Campaign version:

## Causal trace

For each material outcome, record the exposure, observable signal, triggering command or scheduled effect, response window, immediate effect, delayed effect, and resolution.

## Plausibility classification

Classify each sampled outcome as plausible, implausible, or indeterminate. Link the command and event sequence that supports the classification.

## Exploit review

Record any command sequence that creates cash, financing, customers, evidence, capacity, tax benefits, or liability relief without a finite source, eligibility gate, delay, or corresponding downside.

## Sign-off

State whether the trace is acceptable for public beta and list unresolved blocking issues.
