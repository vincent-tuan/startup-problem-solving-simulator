# Scenario 2.1 release checklist

- [ ] Scenario content validates and published versions are immutable.
- [ ] Existing 2.0.x replay tests remain unchanged.
- [ ] Debt requests, offers, draws, service, covenants, delinquency and default are tested.
- [ ] Equity opportunities are scarce, delayed, expiring and stage-sensitive.
- [ ] Segment sourcing inventory is finite and saturation reduces response.
- [ ] Invoice collection supports late, partial, disputed and write-off outcomes.
- [ ] Manual collection never posts cash directly.
- [ ] Hidden eligibility and exact probabilities are absent from client projection.
- [ ] Lint, typecheck, unit, legacy, build and browser suites pass.
- [ ] Calibration compares 2.0.x and 2.1.x ending and policy distributions.
- [ ] Finance and founder-operator reviewers sign off on sampled traces.
